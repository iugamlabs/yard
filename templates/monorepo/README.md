# YardApp

Standard Yard monorepo.

```sh
yard install
yard init
yard user bootstrap owner
yard dev
```

Browser entry: http://localhost:8080. Account settings, organizations and Admin are available from the navigation. Public username registration is enabled. GitHub is disabled until configured. Development mail is captured in the administrator's Mail inbox. Configuration examples: .yard/appsettings.local.json (generated by init). Run yard --help for commands.

`yard new` only generates files. `yard dev` never migrates the database. PostgreSQL uses a checkout-owned Docker container; SQLite runs without Docker. Keep .yard untracked. Use yard check for engineering checks and yard verify for browser acceptance.
